## 📖 نبذة عن المشروع

تُعدّ هذه المنصة أداة مكتبية وسحابية مصممة خصيصاً للمدرسين والمؤسسات التربوية في العراق، حيث تغني عن التنسيق اليدوي المعقد في برامج تحرير النصوص التقليدية. تتيح المنصة كتابة الأسئلة مع المعاينة الفورية، وتوليد ترويسات وزارية رسمية، وإدراج المعادلات الرياضية والكيميائية والأبيات الشعرية والرسومات الهندسية، ثم تصديرها كملف **PDF** جاهز للطباعة بضغطة زر.

---

## ✨ أبرز المميزات

### 🏛️ 1. تنسيق وزاري رسمي ومرن
* **ترويسة ثلاثية متكاملة:** تتضمن شعار جمهورية العراق، اسم المدرسة، العام الدراسي، نوع الامتحان، الدور، المادة، الصف والفرع، والوقت المحدد.
* **دعم الاتجاهين تلقائياً (`RTL` / `LTR`):** تنسيق عربي من اليمين إلى اليسار للمواد العلمية والإنسانية، وتنسيق من اليسار إلى اليمين لمادة اللغة الإنجليزية.
* **تخطيطات طباعة متعددة:**
  * نمط **العمود الواحد** (المدرسي التقليدي).
  * نمط **العمودين** (الوزاري الرسمي).
  * خيارات أحجام الورق: **A4 كاملة**، **A4 نصف صفحة**، **A5**، أو التحجيم التلقائي لضغط الأسئلة في عدد صفحات محدد.

### 🤖 2. مساعد الذكاء الاصطناعي (`gemini-3.6-flash`)
* **📷 قراءة خط اليد (Handwritten OCR):** رفع صور لأوراق أسئلة مكتوبة بخط اليد وتحويلها فوراً إلى نص منسق مع معادلاته.
* **📚 استخراج الأسئلة من الكتب والملازم:** تحليل ملفات PDF أو صور الكتب المدرسية وانتقاء أسئلة بمستوى وزاري حسب شروط المدرس.
* **⚡ توليد نماذج امتحانية متكاملة:** إنشاء ورقة أسئلة كاملة مع توزيع الدرجات والفروع بناءً على الفصول الدراسية المحددة.
* **✨ التدقيق والإصلاح التلقائي:** فحص المسودة وتصحيح صيغ LaTeX والأقواس وتنسيق الفروع والدرجات.

### 📐 3. أدوات متخصصة للمواد الدراسية
* **معادلات رياضية وكيميائية:** دعم كامل لصيغ **LaTeX** عبر محرك KaTeX.
* **رسومات هندسية وفيزيائية مدمجة:** توليد رسومات متجهية (SVG) عالية الدقة للأشكال الهندسية والدوائر الكهربائية.
* **تنسيق أدبي وديني:** محاذاة تلقائية للأبيات الشعرية (صدر وعجز)، وتنسيق الآيات القرآنية، وجداول المقارنة، ومربع الثوابت العلمية.

## 📚 المواد الدراسية المدعومة

| المادة الدراسية | اتجاه الورقة | أبرز الخصائص المدمجة |
| :--- | :---: | :--- |
| **الرياضيات** | `RTL` | معادلات LaTeX، تكاملات ومصفوفات، رسومات هندسية ودوال |
| **الفيزياء** | `RTL` | مربع الثوابت الفيزيائية، دوائر تيار متناوب (RLC)، عدسات ومقارنات |
| **الكيمياء** | `RTL` | معادلات كيميائية متزنة، رموز العناصر، مربع الكتل الذرية |
| **اللغة العربية** | `RTL` | تقسيم القواعد والأدب، تنسيق الأبيات الشعرية (صدر وعجز) |
| **التربية الإسلامية** | `RTL` | تنسيق الآيات القرآنية والأحاديث النبوية وأحكام التلاوة |
| **الأحياء** | `RTL` | التعاريف، المقارنات، الموقع والوظيفة، إرفاق الصور التوضيحية |
| **اللغة الإنجليزية** | `LTR` | ترويسة إنجليزية رسمية، تنسيق القطع الاستيعابية والقواعد |

## 🛠️ دليل الأوسمة والتنسيق السريع داخل المحرر

| الغرض | الصيغة المستخدمة في المحرر | النتيجة في الورقة |
| :--- | :--- | :--- |
| **معادلة سطرية** | `$E = mc^2$` | معادلة داخل السطر |
| **معادلة مستقلة** | `$$\int_{0}^{1} x^2 \, dx$$` | معادلة في منتصف السطر |
| **بيت شعري** | `صدر البيت ... عجز البيت` | شطران متقابلان ومتوازيان |
| **مثلث قائم** | `[diagram: triangle]` | رسم مثلث قائم مع الزاوية والأبعاد |
| **دائرة كهربائية** | `[diagram: rlc_circuit]` | رسم دائرة تيار متناوب (R-L-C) |
| **دائرة هندسية** | `[diagram: circle]` | رسم دائرة مع المركز ونصف القطر |
| **رسم دالة / عدسة** | `[diagram: parabola]` / `[diagram: optics_lens]` | رسم بياني أو مسار أشعة |
| **صورة مرفوعة** | `[صورة: 1]` | إدراج الصورة المرفوعة برقمها |

## 🚀 التثبيت والتشغيل المحلي

### 1. استنساخ المستودع
```bash
git clone https://github.com/AliAsaadMM/Exam-Generator-Project.git
cd Exam-Generator-Project
```

### 2. إنشاء بيئة افتراضية وتثبيت المكتبات
```bash
python -m venv venv

# تفعيل البيئة على نظام Windows:
venv\Scripts\activate

# تفعيل البيئة على نظام Linux / macOS:
source venv/bin/activate

# تثبيت المتطلبات:
pip install -r requirements.txt
```

### 3. تشغيل التطبيق
```bash
streamlit run app.py
```
سيفتح التطبيق تلقائياً في متصفحك على العنوان: `http://localhost:8501`

## 🔑 إعداد الذكاء الاصطناعي (`gemini-3.6-flash`)

1. احصل على مفتاح API مجاني من منصة [Google AI Studio](https://aistudio.google.com/).
2. أدخل المفتاح في حقل **Gemini API Key** داخل الشريط الجانبي للتطبيق، أو أنشئ ملف `.env` في المجلد الرئيسي وأضف بداخله:
   ```env
   GEMINI_API_KEY=AIzaSy_your_api_key_here
   ```

## ☁️ النشر على Streamlit Community Cloud

المشروع مهيأ بالكامل للنشر المجاني عبر **Streamlit Cloud** بفضل وجود ملف `packages.txt` الذي يثبّت مكتبات النظام الخاصة بمحرك طباعة الـ PDF (`WeasyPrint`) تلقائياً:
1. اربط حسابك في [Streamlit Cloud](https://share.streamlit.io/) بمستودع GitHub.
2. اختر المستودع `iraqi-exam-generator` والملف الرئيسي `app.py`.
3. اضغط **Deploy**.
